# 報價系統資安與開發規範 (Quote Safety Rules)

本專案為台灣機械業報價與 ERP 系統，所有程式碼撰寫、修改與維護必須無條件嚴格遵守以下安全規範：

---

### 1. 成本與底價保護 (嚴禁洩漏底價)
- **規則**：GAS (Google Apps Script) 或任何 API 讀取、查詢庫存表 (`Inventory`) 或產品價目表時，**必須於後端程式中過濾並剔除 `cost_price` (進貨成本 / 底價) 欄位**。
- **要求**：
  - 嚴格禁止將包含 `cost_price` 的原始資料物件、陣列或工作表範圍直接回傳至前端或公開 API。
  - 僅允許對外提供公開參考單價、規格及可售庫存量，確保商業機密與底價安全。

---

### 2. LINE 查詢業務身分驗證 (業務白名單機制)
- **規則**：透過 LINE Messaging API / LINE Bot 進行任何報價單、庫存或客戶查詢時，**必須強制驗證 `ALLOWED_SALES_IDS` 業務白名單**。
- **要求**：
  - 後端收到 LINE Webhook 事件時，先比對發送者的 `userId` 是否存在於 `ALLOWED_SALES_IDS` 清單中。
  - 若非白名單業務人員，一律拒絕存取並回傳權限不足警告，嚴禁回傳任何企業內部商業與報價數據。

---

### 3. 語言與術語標準 (台灣機械業繁體中文)
- **規則**：所有使用者介面 (UI)、註解、欄位名稱、報價單條款及文件說明，**一律使用台灣機械業繁體中文標準術語**。
- **常見術語對照**：
  - 機台 / 機構 / 加工件 / 夾治具 / 耗材 / 刀具
  - 統編 (統一編號) / 幣別 (新台幣 TWD) / 未稅金額 / 營業稅 (5%) / 含稅總額
  - 訂金 / 驗收款 / 交期 (出貨天數) / 保固期 / 試車驗收

---

### 4. 程式碼同步規範 (自動執行 Clasp 同步)
- **規則**：凡修改本地端 `Code.js` (或 `src/Code.gs`) 後，**必須自動執行 `clasp push -f` 將最新程式碼強制同步至 Google Apps Script 雲端環境**。
- **要求**：
  - 修改後立即檢查並執行同步指令，確保本地程式庫與線上 GAS 部署版本隨時維持一致。
